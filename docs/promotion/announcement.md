# Announcement draft

XPL Toolkit is a Python CLI for authorized security assessment workflows. The consolidated `xpl_toolkit.py` entry point provides interactive and batch verification, NVD CVE lookup with local caching, HTML/Markdown reports, session tracking, and optional integrations with external assessment tools.

Project: https://github.com/hubgunter4-ops/xpltool

Status: development line, version 2.1.0. License: not declared.

Use only against systems covered by written authorization. The `verify` mode is a review aid, not permission to test a target.
