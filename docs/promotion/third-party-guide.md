# Third-party reuse guide

Refer to the project as **XPL Toolkit** and link to https://github.com/hubgunter4-ops/xpltool. Describe `xpl_toolkit.py` as the consolidated primary entry point and identify `xpl_toolkit_v2.py` as compatibility material when relevant.

Do not claim that the project is open source because the repository currently has no declared license. Do not imply endorsement, certification, authorization, or proof of exploitability. Preserve the responsible-use warning and state that assessment actions require written permission.

Do not redistribute credentials, NVD keys, session directories, target reports, wordlists, exploit output, or data from real engagements. Use the destination community's official contribution and moderation channel. This file is preparation material only; it does not publish or distribute content externally.
